CVE-2026-116400

            
WordPress Button Block plugin <= 1.2.7 - Cross Site Scripting (XSS) vulnerability

        

        

            Date: Oct 26, 2026
            Assigner: Patchstack
            CVSS 3.1
        

    


    

        
        
        

            
Target Scope

            

                Button Block
                (bPlugins)
            

        


        
        

            
Description

            

                
Improper Neutralization of Input During Web Page Generation ('Cross-site Scripting') vulnerability in bPlugins Button Block button-block allows Stored XSS.This issue affects Button Block: from n/a through 1.2.7.

            

        


        
        

            
            

                
Metrics (CVSS 3.1)

                

                    

                        

                            6.5
                            MEDIUM
                        

                        

                            

                        

                    

                    
                    

                        Vector:
                        CVSS:3.1/AV:N/AC:L/PR:L/UI:R/S:C/C:L/I:L/A:L
                        
                    

                

            


            
            

                
Weakness (CWE)

                

                    

                        CWE-79
                    

                

            

        


        
        
        

            
Affected Software & Versions

            

                
    
                    
                        
  • 
                            Button Block
                            (bPlugins)
                             — ≤ 1.2.7
                        
    • 
                    
                

            

        


        
        
        

            
Solution & Remediation

            

                
Update the WordPress Button Block plugin to the latest available version (at least 1.2.8).
